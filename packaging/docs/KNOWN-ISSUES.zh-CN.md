# 远联 0.2.0 已知问题与阻塞

## 交付阻塞

1. **Linux 客户端未在真实桌面验收。** 已在 WSL Ubuntu 用 Flutter Linux 构建出 deb/便携包，`dpkg-deb`/`ldd`/Xvfb 启动检查通过；但没有 X11/Wayland 真实桌面，安装/升级/卸载、显示、输入与桌面集成未实测，不能标记 Linux 实机通过。
2. **Windows 安装器/二进制未做代码签名。** 没有 Windows 代码签名证书；系统会显示未知发布者。安装器仍可安装，但不能宣称“可信发布者/签名成功”。Android 仅使用独立预览签名，不是正式升级链。
3. **账号 UI 未完成真实点击登录 E2E。** 登录/注册/设备/配对页面有 HTTP mock 与响应式测试；服务端 API、票据连接、撤权已用真实本机服务端实测。Android 模拟器账号页可打开，但键盘/分段按钮导致本轮未完成真实登录点击。
4. **未升级已部署的 `192.168.9.66` 服务端。** 本轮只在 WSL 本机隔离库验证；没有操作生产服务器、nginx、防火墙或数据库。部署前需备份并按 server 包内脚本执行。
5. **Docker Compose 未验证。** 本机没有 Docker，只交付定义文件；不能在未构建的情况下声称镜像可用。

## 功能缺口

- Rust FFI/native texture：Flutter 仍用 Dart 合成 JPEG 图块，画面与解码性能不是最终形态。
- Linux 主控/Host、Android 被控 Host、X11/Wayland Portal/PipeWire、MediaProjection 未实现。
- 质量模式（Sunshine/moonlight-common-c）、完整兼顾/流畅模式、模式切换/回滚、1 Mbps 总预算、拥塞控制未实现。
- NAT 穿透、授权中继、QUIC、面向中继的 E2EE 未实现；中继“看不到明文”未验证。
- 音频、麦克风、剪贴板、手柄、相对鼠标/拖拽捕获、完整多显示器/混合 DPI 未实现。
- 文件：无目录传输、拖放、断点续传、块级校验、幂等重试、任务中心、SAF、ACL/审计；删除权限未开放；文件与画面共用 TCP。
- Android：双指捏合未实机手势验证；完整 IME/中文候选窗、SAF、实体触控、后台/锁屏行为未验收。
- 本机授权只有一次性 MessageBox；无托盘、服务安装、无人值守白名单/时段、长期信任分层。Session 0 服务不能显示桌面对话框，必须拒绝。
- MFA/恢复码、完整 S01–S10、策略 schema/下发/确认/回滚、备份恢复、告警、会话/中继容量未实现。
- 未完成跨物理机/局域网/公网、弱网 1 Mbps、2 小时稳定性、4 GiB/万文件、断网续传、完整故障注入与安全专项。
- Windows 采集仍为 GDI；3200×2000 本轮约 7–9 fps、采集 51–55 ms、编码 24–33 ms，不能换算成完整会话验收。

## 已知限制/操作注意

- Host 默认拒绝所有无票据连接；只有 `--allow-anonymous` 的隔离测试模式例外，启动会告警。
- 票据默认 1 小时；到期后会话结束，需要重新授权。Host 断联控制面 30 秒后按失败关闭策略结束票据会话。
- 票据私钥存服务端 SQLite；未做 HSM/磁盘加密。`YUANLIAN_ROTATE_TICKET_KEY=1` 启动一次可轮换，旧票据在过期前仍可验证；需要立即失效请中心撤权。
- Windows 卸载默认保留 `%LOCALAPPDATA%\YuanLian` 的设备身份/登录令牌；卸载对话框选择删除会永久清空，需用户明确确认。
- 中文路径会导致 Windows Flutter AOT/MSBuild 失败；发布包从 ASCII 路径副本构建，安装后运行不依赖源码路径。
- Android 预览签名变化时不能静默卸载清数据；正式发布前必须由用户提供并妥善保管正式密钥。

## WebUI / P2P 当前边界（2026-10-18 增量）

- R1–R6 已修复并有隔离 API/真实 Host 回归；仍未做 2 小时/高并发/时钟偏差和完整跨网验收。
- WebUI 使用 1–2 秒受控轮询，不是 SSE/WebSocket；非管理员全边界、360/768/200% 缩放和深色逐页未全部验收。
- 会话“已请求撤销”与“Host 已确认结束”已分开显示；Host 崩溃后的状态由 30 秒租约清理，不能保证精确到秒。
- **P2P/ICE/STUN/TURN/中继未实现。** 当前只有 TCP/TLS 直连；网络页明确显示未实现，不提供假测试按钮或假吞吐。跨 NAT、TURN、DTLS/SCTP 数据通道、端点身份绑定和媒体 E2EE 需在锁定依赖与独立网络环境后另行验收。
